Склад: учёт товаров и операций

Программа для автоматизированного учёта товаров на складе с возможностью отслеживания прихода, расхода и текущих остатков.
📋 О программе

Программа предназначена для ведения складского учёта с удобным интерфейсом и поддержкой всех необходимых операций. Подходит для малого и среднего бизнеса, позволяет эффективно управлять товарными запасами.
Основные возможности:

    📦 Ведение реестра товаров с названиями и штрихкодами (GTIN)

    📊 Регистрация прихода и расхода товаров с указанием количества и даты

    💰 Автоматический расчёт текущих остатков на складе

    📜 Просмотр полной истории операций по каждому товару

    🔍 Сортировка товаров и операций для удобного поиска

    💾 Автоматическое сохранение всех данных в локальной базе

    🔄 Автообновление интерфейса при изменении данных

✨ Возможности программы
Вкладка «Товары»

    ➕ Добавление новых товаров с названием и GTIN

    ✏️ Редактирование существующих товаров

    🗑️ Удаление товаров (с каскадным удалением всех операций)

    🔼🔽 Изменение порядка сортировки товаров

    📋 Таблица со всеми товарами и их кодами

Вкладка «Операции»

    📥 Регистрация прихода товара

    📤 Регистрация расхода товара

    📅 Выбор даты операции (с календарём)

    ✏️ Редактирование существующих операций

    🗑️ Удаление операций

    📋 Таблица со всеми операциями с сортировкой по дате

Вкладка «Остатки»

    📊 Автоматический расчёт остатков по каждому товару

    📈 Отображение общего прихода и расхода

    🟢 Жёлтый цвет - положительный остаток

    🔴 Красный цвет - отрицательный остаток (ошибка учёта)

    ⚪ Серый цвет - нулевой остаток

    🖱️ Клик по товару - переход к истории его операций

🗄️ Структура базы данных
Таблица products (Товары)
Поле	Тип	Описание
id	INTEGER PRIMARY KEY	Уникальный идентификатор
name	TEXT NOT NULL UNIQUE	Название товара
gtin	TEXT	Штрихкод (GTIN)
sort_order	INTEGER DEFAULT 0	Порядок сортировки
Таблица movements (Операции)
Поле	Тип	Описание
id	INTEGER PRIMARY KEY	Уникальный идентификатор
product_id	INTEGER NOT NULL	ID товара (внешний ключ)
mtype	TEXT NOT NULL	Тип операции: 'in' (приход) или 'out' (расход)
qty	REAL NOT NULL	Количество
date	TEXT NOT NULL	Дата операции (YYYY-MM-DD)

🚀 Установка и запуск
Способ 1: Запуск из исходного кода

Требования:

    Python 3.8 или выше

    Установленные зависимости:

python inventory_app.py

Способ 2: Сборка EXE (PyInstaller)

# Установить PyInstaller
pip install pyinstaller

# Собрать EXE
pyinstaller --onefile --windowed --name "Inventory" --icon="ico\app.ico" --add-data "ico;ico" inventory_app.py

📖 Руководство пользователя
1. Добавление товара

    Перейдите на вкладку «Товары»

    Введите Название товара

    (Опционально) Введите GTIN (штрихкод)

    Нажмите кнопку «Добавить»

2. Редактирование товара

    Выберите товар в таблице

    Нажмите «Изменить»

    Отредактируйте поля

    Нажмите «Обновить»

3. Удаление товара

    Выберите товар в таблице

    Нажмите «Удалить»

    Подтвердите удаление

4. Изменение порядка товаров

    Выберите товар в таблице

    Нажмите «Вверх» или «Вниз»

5. Создание операции

    Перейдите на вкладку «Операции»

    Выберите Товар из списка

    Выберите Тип (Приход/Расход)

    Введите Количество

    Выберите Дату (по умолчанию сегодня)

    Нажмите «Сохранить»

6. Редактирование операции

    Выберите операцию в таблице

    Нажмите «Изменить»

    Отредактируйте поля

    Нажмите «Обновить»

7. Удаление операции

    Выберите операцию в таблице

    Нажмите «Удалить»

    Подтвердите удаление

8. Просмотр остатков

    Перейдите на вкладку «Остатки»

    Увидите текущие остатки всех товаров

    Кликните на любой товар, чтобы увидеть историю его операций

    Python 3.8 - язык программирования

🐛 Известные проблемы и их решение
Проблема	Решение
Не отображаются иконки	Проверьте наличие папки ico с файлами рядом с программой
База данных заблокирована	Закройте все экземпляры программы
Ошибка при вводе количества	Используйте точку (.) или запятую (,) для десятичных чисел
Календарь не открывается	Установите pip install tkcalendar
Отрицательный остаток	Проверьте корректность операций (возможно, расход превысил приход)

🔧 Конфигурация

Программа использует локальную базу данных inventory.db в папке с программой.

Путь к иконкам: папка ico в директории программы.

📝 Примечания

    База данных inventory.db создаётся автоматически при первом запуске

    Для работы иконок необходимо наличие папки ico с файлами

    При удалении товара автоматически удаляются все связанные операции

    Программа не требует административных прав для установки

    Поддерживается работа с общей базой данных в сети
