# 📦 Склад: учёт товаров и операций (Товарный расчёт 2.0)

Программа с графическим интерфейсом (GUI) для автоматизированного учёта товаров на складе. Позволяет вести базу номенклатуры, фиксировать приход и расход, контролировать текущие остатки и выгружать отчёты в Excel.

## ✨ Основные возможности

- **Ведение реестра товаров**: Добавление, редактирование и удаление товаров, указание названия и штрихкода (GTIN).
- **Управление операциями**: Регистрация прихода и расхода с указанием количества и даты (встроенный календарь).
- **Контроль остатков**: Автоматический расчёт текущего количества на складе. Клик по товару открывает историю всех его операций.
- **Сортировка**: Возможность менять порядок отображения товаров (кнопки «Вверх» и «Вниз»).
- **Экспорт в Excel**: Сохранение отчёта по остаткам в формате `.xlsx` на рабочий стол (в папку «Учёт остатков») с автоматической подстройкой ширины колонок и красивым форматированием.
- **Автообновление**: Программа автоматически отслеживает изменения в базе данных и обновляет интерфейс.
- **Встроенные иконки**: Все иконки интерфейса вшиты в код (base64), поэтому программа не требует наличия внешней папки `ico/` при запуске.

## 🛠 Технологии

- **Язык**: Python 3.8+
- **Интерфейс**: Tkinter / ttk
- **База данных**: SQLite3 (локальный файл `inventory.db`)
- **Экспорт**: OpenPyXL
- **Изображения**: Pillow (PIL)
- **Календарь**: tkcalendar
- **Сборка**: PyInstaller

## 🚀 Запуск из исходного кода

1. Убедитесь, что у вас установлен Python 3.
2. Установите необходимые зависимости:
   ```bash
   pip install pillow tkcalendar openpyxl
   ```
3. Запустите главный файл:
   ```bash
   python inventory_tk.py
   ```

## 📦 Сборка в EXE (Windows)

Для создания автономного исполняемого файла используется скрипт `build.bat`. 
Перед сборкой установите PyInstaller:
```bash
pip install pyinstaller
```

Запустите сборку:
```bat
build.bat
```
*Скрипт автоматически очистит предыдущие сборки (`build/`, `dist/`, `*.spec`), сгенерирует встроенные иконки из папки `ico/` и соберёт новый `exe` файл.*

Готовый файл появится в папке `dist\Товарный расчёт 2.0.exe`.

## 📂 Структура проекта

```text
├── inventory_tk.py         # Точка входа в программу
├── build.bat               # Скрипт сборки в EXE
├── generate_icons.py       # Скрипт генерации встроенных иконок
├── ico/                    # Папка с исходными иконками (для сборки)
├── inventory.db            # Файл базы данных (создается автоматически)
└── inventory/              # Основной пакет приложения
    ├── __init__.py
    ├── app.py              # Главный класс приложения (окно, вкладки)
    ├── config.py           # Конфигурация (пути, цвета, версия)
    ├── db.py               # Работа с SQLite (подключение, инициализация)
    ├── utils.py            # Вспомогательные функции (форматирование, пути)
    ├── icons.py            # Загрузчик иконок
    ├── styles.py           # Настройка стилей ttk
    ├── widgets.py          # Кастомные кнопки и элементы
    ├── embedded_icons.py   # Сгенерированный файл с base64 иконками
    ├── products_tab.py     # Логика вкладки "Товары"
    ├── movements_tab.py    # Логика вкладки "Операции"
    └── balances_tab.py     # Логика вкладки "Остатки" и экспорт в Excel
```
